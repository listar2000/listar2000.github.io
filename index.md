<h2 class="home-h">research</h2>
<dl class="areas">
  <dt>Training agents</dt>
  <dd>Core contributor to <a href="https://github.com/rllm-org/rllm">rLLM</a>, an open-source framework for agentic RL; making reasoning models stop overthinking (<a href="https://arxiv.org/abs/2504.21370">ShorterBetter</a>).</dd>
  <dt>Evaluating models</dt>
  <dd>Building <a href="https://www.prophetarena.co/">Prophet Arena</a>, which tests LLMs on forecasting real-world events; studying what <a href="https://www.arxiv.org/abs/2509.23488">benchmarks measure</a> and how <a href="https://arxiv.org/abs/2506.17871">alignment narrows</a> what models generate.</dd>
  <dt>Prediction-powered inference</dt>
  <dd>Estimators that combine a small amount of reliable data with a large amount of cheap ML predictions, using empirical Bayes ideas for guarantees (<a href="https://arxiv.org/abs/2502.14166">PAS</a>).</dd>
</dl>
